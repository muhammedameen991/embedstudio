## ✨ What is EmbedStudio?

**EmbedStudio** is a premium, frontend-only video embed builder that lets you create a responsive video player from an authorized video or iframe source.

Configure your player, preview it instantly, and copy the generated iframe code.

> ⚡ No server.  
> ⚡ No database.  
> ⚡ No backend.  
> ⚡ Everything runs directly in your browser.

---

## 🚀 Features

| Feature | Description |
|---|---|
| 🎬 Live Preview | Instantly preview your embedded player |
| 📱 Responsive | Designed for desktop, tablet and mobile |
| 🎨 Custom Player | Customize title, poster and presentation |
| 🖼️ Poster Image | Add a custom poster image |
| 📐 Multiple Ratios | 16:9, 4:3 and 1:1 |
| 🔲 Rounded Corners | Enable or disable cinematic corners |
| 🌑 Shadow | Add an elevated player effect |
| 📋 Copy Code | One-click iframe code copying |
| 💾 LocalStorage | Automatically remembers your last configuration |
| ⚡ No Backend | 100% client-side |
| 🔐 Authorized Sources | Designed for content you own or are authorized to embed |
